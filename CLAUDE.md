## 1. Project Overview
- **Title:** IronFauna · Unity `6000.6.8f1` · URP `17.6.0` · Input System only.
- **The game (owner, 2026-11-17/18): a Gang Beasts-style physics mech brawler.** Humanoid robots fight with MMA moves, grapple, throw and slam, and tear each other apart limb from limb; every strike is readable and committed, with real weight (For Honor / Dark Souls). Targets: **8-player online + local co-op** (split screen, the camera sits behind your own mech), **destructible arenas and fighters**, a garage to build fighters from clamshell armor.
- **Removed 2026-11-18 at the owner's request** ("remove the deploy, remove anything not related to the mech fighting game, remove the four-legged one"): the tower-defence game (objective core, enemy walkers, turrets, grid), Deploy and the piloting/shooting code (`MechPilotController`, `MechPilotCamera`, `MechRobotOperator`, `MechFleetCoordinator`), Antigravity's HUD and input controller, `SampleScene`, the boxing-ring prototype, the Unity template readme, and the whole quadruped chassis (builder code, garage option, 44 models, Blender generators). All of it is in git history before commit "Clean up: fighting game only".
- Scenes: `Assets/Scenes/MainMenu.unity` is the only scene; the brawl runs inside it (FIGHT builds the arena, Esc reloads the scene).

## 1b. Launcher & Releases (owner 2026-11-18: "a launcher so my friends can easily install the game and get the latest update", Warframe-launcher inspired, same setup as the RoR2 Broken Characters launcher)
- `Launcher/` — WPF .NET 8 single-file exe `IronFauna-Launcher.exe` (HOME / PATCH NOTES / SETTINGS, INSTALL/UPDATE/PLAY, progress + speed/ETA, unpack to `<dir>.new` then swap folders, offline play, repair, uninstall, desktop shortcut, self-update by exe size from `launcher-info.json`, `--screenshot <png>` preview mode). Install dir default `%LOCALAPPDATA%\IronFauna\Game`, settings `%LOCALAPPDATA%\IronFauna\launcher.json`. Builds on Linux too with the Microsoft SDK (`EnableWindowsTargeting`).
- Everything is read from the public release tag `latest` via `https://github.com/a6407805-alt/IronFauna/releases/latest/download/<file>`: `release-info.json` (version, zip, zipSize, exe, published, title, notes, art), `patch-notes.json` (newest first, last 30), `IronFauna-Windows.zip`, `launcher-art.png`, `IronFauna-Launcher.exe`, `launcher-info.json`, `launcher-preview.png`.
- `.github/workflows/launcher.yml` builds the launcher on windows-latest when `Launcher/**` changes, screenshots it and uploads exe + preview, then `launcher-info.json` last.
- The game is NOT built in CI (no Unity license there): `IronFauna > Publish Update...` (`Assets/Editor/IronFaunaPublisher.cs`) builds StandaloneWindows64 into `Builds/Windows/IronFauna.exe`, zips it, and uploads zip → art → patch-notes.json → release-info.json (last) with the owner's fine-grained GitHub token (Contents read/write, IronFauna only) stored in EditorPrefs. `IronFauna > Capture Launcher Art (Play mode)` saves `Builds/launcher-art.png`. `Builds/` is gitignored.

## 2. Art Bible & Visual Rules (`Assets/Scripts/Core/IronFaunaPalette.cs`)
- **Style:** realistic hard-surface mecha — physically based metal and coated paint (URP Lit), a dark hangar studio for the title/garage (key/rim/fill lights, generated reflection cubemap, ACES, restrained bloom), an outdoor rocky island for brawls (sun, sky fill, haze). `IronFaunaMaterials.Realistic` (default true); false restores the old toon shader.
- **Presentation:** title and garage show the mech in `MechClamshellBuilder.showcasePose` with `MechShowcaseStage.AnimateIdle`.
- **Lessons:** big flat glossy surfaces mirror the lights into white glare — keep them matte (`MakeMatte`). `Mathf.SmoothStep(a, b, t)` interpolates; it is not GLSL `smoothstep` (use `Ramp`).
- **Garage UI skin:** dark translucent panels, `Ui*` palette text colours, 2400×1350 reference canvas.
- **Palette (single source of truth — never use literal `Color.*` outside `IronFaunaPalette.cs`):** `CrimsonFront` `#C8282E` (front halves) · `MaroonRear` `#6E1E26` (back halves) · `GunmetalFrame` `#3A3F46` · `DarkIron` `#23272D` · `OffWhitePanel` `#F0ECE1` · `HazardYellow` `#E6B800` · `ShadowSlate` `#1E2229` · `OrangeJointCore` `#FF7A1A` · `CyanEnergy` `#24E5FF`, plus `Steel*`, `Studio*`, `Terrain*`, `SkyHaze`, `SunWarm` and the paint schemes.

## 3. Two-Layer Build: Skeleton + Clamshell Armor (180 parts, 10 sets, 3 weight classes)
- Every mech is (1) a structural skeleton that looks finished on its own and (2) two-piece clamshell armor that clamps onto it (front half crimson, back half maroon, toggle latches, seams down the sides only). Visual blend: Armored Core 4/For Answer + Zoids + Gundam inner frames.
- **Exposed joint hubs:** armor stops short of every joint drum with 45° bevelled clearance; never cover a joint.
- Leg stance enum (`LegPosePreset`, 5 stances) still exists in the builder; fighters always use `Pose1_HumanLeg`.
- Not built yet: overlapping knee armor, separate leg types, armor that changes fighting stats beyond the garage numbers.
- Part catalogues: `Docs/ironfauna_*_clamshell_catalog.md`, `Docs/Blueprints/*.jpg`; design summary `Docs/GDD_and_Clamshell_Architecture.md`.

## 5. Leg Clearance Rules (verified numerically)
- Shell ends stop `jointRadius + 0.06` from each hub and bevel 45° (depth shrinks by `0.15`).
- Thigh details live on the hip-side band (`0.02..0.38` of shell length), calf details on `-0.22..0.10`, so a deep fold cannot close details together.
- `Tools/Blender/fold_check_all.py <blend> [--aw --ad --ai --jr]` checks thigh/calf/foot of every set in all 5 stances per weight class.

## 6. Modeled Parts (Blender → FBX)
- `Assets/Resources/ClamshellMeshes/<Slot>_<Set>.fbx` replaces the procedural half for that slot/set; `ClamshellMeshLibrary` re-orients and fits it into the slot envelope. Material names pick the colour role: Shell, Panel, Hazard, Dark, Frame, Glow, Copper.
- Plate authoring: bone along Blender Z, plate on the -Y side with its inner face at Y = 0, depth about 1.6× the envelope depth. Feet (`FootFront/FootBack`) are lengthwise parts at true size: X width, Z length (+Z = toe/heel tip), height toward -Y; `TryGetLengthwise` scales them uniformly.
- **`Tools/Blender/aero_sets.py` builds all 180 armor parts** (second-generation angular shapes; Set01 from `aero_ironclad.py`; sets 02-10 = dart + hood base with each set's signature from `clamshell_sets.py`, which is now a library). `ironclad.py` holds `Part` (polish: smooth shading, 9 mm 2-segment bevel, weighted normals; FBX with `mesh_smooth_type="OFF"`).
- **Third generation (2026-11-17, owner: "sleek and polished"; Set01 only, as a test):** `Tools/Blender/sleek_ironclad.py` — dense smooth car-body surfaces with crisp shoulder lines, gapped raised panels, inlaid lines, swept fins, fan-triangulated caps. If approved, port sets 02-10 to it. The owner found the result clean but "more boxing game"; the art direction is still open.
- `Tools/Blender/skeleton.py` builds 23 `Skel_*.fbx` pieces (humanoid torsos per class, limb bones, feet, hand, head, joints, joint guard). Skeleton pieces are true size, never fitted (`TryGetRaw`). Mirrors `MechFrameSpec` — change both together.
- Materials: skeleton = matte cast metal (`SteelCast`), recesses `SteelBlack`, armor = satin coated composite; shared generated wear map; emissives razor-thin.
- Delivery: zip with `Assets/...` entries at `<project>/ModelDrop/models.zip`, then `IronFauna > Import Model Drop` (auto-runs only on a script reload). Zips over ~10 MB go by file UUID (SendUserFile).

## 7. Skeleton, Weight Classes & Hardpoints
- `MechFrameSpec`: Light/Medium/Heavy frame thickness, armor width/depth, seam offset, joint radius, hip/shoulder/collar spacing. **Mirrors `CLASSES` in `Tools/Blender/skeleton.py`.**
- `torsoWeight` (torso, arms, hardpoint sizes) and `legWeight` (legs) are independent, saved in `MechLoadout`, and change stats and the walk cycle profile. `showArmor = false` shows the bare skeleton.
- Clearance: where armor clamps on, the skeleton stays inside the slot between the halves. Head and hands are universal.
- Hardpoints (`MechHardpoint`): `BackUpperL`, `BackUpperR`, `BackCentre`, `LowerSpine`; size by torso class. Unused by the brawler so far.

## 8. The Brawler
- **Milestones:** (1) active-ragdoll fighters [done]; (2) strikes, guard, poise, knockdowns, kicks/knees/elbows [done]; (3) grapples, throws, slams, suplexes, floor body-drag & Jiu-Jitsu joint cranks [done]; (4) 8-player UDP networking (`MechBrawlNet`) + 8-player vs AI 5-Act Co-Op Campaign [done]; (5) 1–4 player split-screen local co-op + 5 destructible stages + Light/Medium/Heavy robot advantages [done].
- **Each fighter = a hidden animated ghost + a physical body.** The ghost (`MechClamshellBuilder` + `MechGaitAnimator` + `MechBoxer` + input or AI) moves and poses; `MechRagdoll` turns a second builder into Rigidbody segments (pelvis = visualRoot, torso, head, upper/forearms, thighs/calves/feet; box colliders; ConfigurableJoints with slerp drives) that follow it. While standing, pelvis and legs are **kinematic copies** of the walk cycle (owner: Deploy's legs were "almost perfect"); torso, arms and head stay physical so hits rock them. Knockdown, being grabbed, or no floor under the hips (`SupportUnder`) = whole body limp; get-up re-centres the ghost and blends back over 0.6 s. Physics step 1/90 s in a match.
- **Movement & Ground Game (MMA Crouch & Jiu-Jitsu Floor Sit):** camera-relative WASD (`moveReference`), Ctrl sprint, X/Alt deep MMA crouch, Z Jiu-Jitsu floor sit / butt-scoot (`MechGaitAnimator.crouchBlend` & `seatedBlend`). While seated on the floor, WASD scoots the mech across the mat using hands and heels, kicking throws an `Upkick`, and holding an opponent with G drags their body across the floor with +65% joint-crank limb-tearing bonus (`RMB`).
- **Technical combat (owner 2026-11-18: "everything explodes ... Dark Souls / For Honor, respect your opponent"; chose no lock-on and simple block + parry):** every move costs stamina (`MechBoxer.staminaCost` = 7 + damage×0.95; dodge 15-27, grab 18, sprint drains); an empty bar = `Exhausted` (no attacks/dodges/sprint until 35%). Shift guard blocks frontal blows (`MechRagdoll.ReceiveFighterStrike`: chip 8%, stamina = damage×1.7×`guardBreak`, empty bar = `BreakGuard`); tapping guard within `parryWindow` (0.2 s) before contact parries (attacker `OnParried` reels 1 s, defender gets a 1.1 s riposte: ×1.8 damage, ×2.2 poise); C dodge = committed step with 0.28 s i-frames (`Evading`); takedowns and floor sweeps are `unblockable`; hits during a wind-up/recovery are counters (×1.3); whiffs (×1.45) and blocked blows (×1.35) recover slower. Knockback cut ~70% (`knockbackScale` 1, shove ×5), torso hits never pick a random limb, limbs 80 HP, head 90, poise 50. Second pass (owner: still too chaotic): strike damage ×0.75 (`StrikeDamageScale`), contact-speed factor 0.8-1.1, hits capped at 30 (falls 25), limb damage ×0.9 on limb hits, and strikes or falls only tear a limb off below 50% hull (`LimbRipHull`; before that the limb sits at 12 HP and sheds armor). Grapple tears are unchanged. Stamina by class: Light 90 / regen 42, Medium 100 / 34, Heavy 120 / 27. AI (`MechBoxerAI`) times parries/dodges/blocks off `WindupRemaining`, punishes `InRecovery`/`Staggered`/`GuardBroken`, ripostes, backs off when tired, grabs turtles. HUD stamina bar + cue popups (PARRY, BLOCK, GUARD BREAK, COUNTER, RIPOSTE, EVADE, EXHAUSTED).
- **20 Martial-Arts Specials & Strikes (`MechBoxer` specs):** LMB jab, RMB cross, Q hook, E uppercut, F front kick, R roundhouse, V low calf kick, Shift guard, C slip; scroll / D-pad picks one of 20 specials (spinning backfist, superman punch, haymaker, spinning elbow, front/low-calf/side/roundhouse/question-mark/axe/spinning-hook/360-tornado/capoeira-sweep kick, flying knee, Muay Thai plum knee, double-leg takedown, flying scissor takedown, Jiu-Jitsu upkick, headbutt, shoulder charge), Space / RT throws it.
- **Weight Classes & 10 Robot Presets (`MechLoadout.ComputeCombatModifiers` & `CreatePreset`):** Light (+34% speed, +22% strike speed, agile floor scoot), Medium (balanced MMA/grappler), Heavy (+38% hull/poise, hyper-armor during wind-ups, heavier mass & slam damage).
- **7 Destructible Stages (`BrawlTerrain` + `BreakableProp` + `FallingTree`):** `BasaltMesa`, `FoundryCrucible`, `OrbitalDish`, `ScrapyardColosseum`, `GlacierTrench`, `NeoMetroCity`, `RedwoodForest`, with breakable pillars (rock spires via `BreakableProp.DressAsRock` on Mesa/Scrapyard/Glacier), walls, containers, buildings, cars, trees and 8 crates. Explosive cells and cars were removed (owner, 2026-11-18). Debris shrinks away after 6-9 s (`DebrisFade`). Props only take damage from strikes or bodies faster than 3.5 m/s; trees need ~260 damage. Cycle stages live with `Tab`.
- **Stage look (`BrawlStageLook`, owner: "really work on the fidelity of the stages"):** per-stage `Look` (sky gradient, sun angle/colour, trilight ambient, linear fog matched to the horizon, ACES + bloom + grade + white balance + vignette volume at priority 50). Ground = 1024² albedo baked from the terrain grid's height/slope (smoothness in alpha; emission for Foundry molten seams and Orbital light rings) + a tiling detail albedo/normal (`_DETAIL_MULX2`); terrain UVs are 0..1. Sky = generated equirect on `Skybox/Panoramic` (falls back to solid colour). Backdrops: valley floor at top-28 (lava, cloud sea, ice, canopy ...), ridge/butte/ice-peak rings, city skyline with lit-window texture and neon, smokestacks, dish feed tripod, colosseum stands, tree wall. Dressing: basalt columns, dry grass/ferns, gantries + railings, relay masts, tyre stacks + car hulks, floodlights, ice spires, traffic lights. Ambient FX: dust, embers, sparkles, snow, rain, leaves. A realtime reflection probe is captured once per arena. Generated assets are released by `BrawlStageLook.Release()` before each rebuild.
- **Modes, Split-Screen & 8-Player Online (`MechBrawlMatch`, `MechBrawlNet`):** 8-Player Free-For-All, 8-Player Co-Op Campaign (5 Acts across all 5 stages with Allied Bots vs Enemy Waves & Giant Bosses), and 4v4 Squad Brawl; 1–4 player split-screen local co-op (`F2` or Title setup); 8-player UDP Host/Client netcode (`:7777`).
- **Tournament Repair Bay (owner 2026-11-21):** `TournamentGarage` (on `TournamentState.garage`, reset per bracket) holds credits, per-part wear (Hull, Head, ArmL/R, LegL/R) and mods. Hits your side lands on the rival pay `damage × 3` CR (+150 for a torn limb). At bout end `CaptureFromFighter` saves wear; at spawn `ApplyToFighter` applies mods then wear (hull floor 20%, missing limbs removed quietly via `MechRagdoll.RemoveLimbQuiet`). `TournamentRepairBay` (bracket → REPAIR BAY) repairs parts (price scales with damage, limb replacement 300), sells 5 legal mods and 5 black-market mods; `RunInspection` before each bout may confiscate illegal mods and fine half their price.
- **Fight HUD (owner 2026-11-22, `BrawlHudExtras`):** no top-left stats card, top-right roster, floating target text or bottom controls ribbon (owner removed them). HP bars float above every robot's head (`MechRagdoll.HeadPosition` + 0.9 m; yours is labelled YOU with a stamina strip under it, red when exhausted). Top-left: robot damage outlines for YOU and TARGET (`IronFaunaPalette.UiStatusGood/Hurt/Bad/Gone` = green / yellow / red / grey: >66% / >33% / below / torn off). Bottom-left: live keyboard + mouse diagram (keys light up while held) with the special-move picker above it. Keep it compact (owner: "make the UI smaller").
- **Announcer (owner 2026-11-22: "fun, Halo-style callouts; the flat mono TTS isn't pleasant"):** `BrawlAnnouncer` shows a banner for everything but voices only `Callouts` (key → line): fight / quarterfinal / semifinal / grand_final, first_blood, combo_3/4/5/6/8 (hits chained within 2.2 s without being hit: Triple strike, Quad strike, Overdrive, Scrap storm, Unstoppable), knockout, double_ko / triple_ko / overkill (player KOs within 5 s, credited to the last hitter within 8 s via `_lastHitBy`), rampage / massacre (3 / 5 KOs in a match), ring_out, final_two, headhunter / arm_off / leg_off / dismembered, denied (parry), punished (riposte), guard_break, counter, victory / defeat / match_over, champion, busted (inspection). `AnnouncerVoice` plays `Resources/Announcer/<key>.wav` if present (recorded or AI-generated lines; never imitate a real announcer's voice), otherwise renders the line once with Windows `System.Speech` (male adult voice, W3C SSML: prosody low / slow / x-loud, strong emphasis, 140 ms breaks between words in short calls) to `temporaryCachePath/AnnouncerVoice_v2/<key>.wav` via a PowerShell worker (render to `<key>.tmp.wav` then rename: the output name must end in .wav or no WAV header is written — that bug made v1 silent; errors are logged as `[IronFauna Announcer]` warnings), then plays it through a stadium-PA chain (pitch 0.86, high-pass, light distortion, slap-back echo, arena reverb). Callouts queue (max 3, dropped after 2.6 s, priority ≥ 4 cuts the queue). Bump `CacheVersion` after changing the voice styling.
- **Tournament Campaign = 10-round gauntlet (owner 2026-11-22; replaces the old 8-mech 3-round bracket):** `TournamentState.rounds[10]` (player vs one rival per round, no AI-vs-AI sim). Rounds 1-4 Act I rivals (skill 0.45→0.60, hull 0.90→1.05), round 5 MINI-BOSS "WARDEN KRAG" (preset 5, skill 0.78, hull ×1.5, scale 1.26, `ApplyBossBuffs` tier 1: damage ×1.18, poise ×1.35, limbs ×1.35, knockback ×0.8), rounds 6-9 Act II rivals (skill 0.64→0.76, hull 1.08→1.26), round 10 GRAND MASTER "GRANDMASTER APEX" (preset 2, AI skill 1.0, hull ×2, scale 1.38, tier 2: damage ×1.4, strike speed ×1.15, stamina regen ×1.8, speed ×1.1, poise ×1.8, limbs ×1.8, knockback ×0.6). Arenas per round in `RoundStages` (no City/Forest). Bracket overlay is a 10-row ladder (Act I left, Act II right). Announcer keys round_1..round_9, mini_boss, grand_master, boss_down.
- **Grab anti-explosion (owner 2026-11-22: "when an enemy grabs me it glitches out and explodes"):** every body Rigidbody has `maxDepenetrationVelocity = 4`, 12 solver / 4 velocity iterations; a held body is carried as one (same `ForceMode.Acceleration` on every segment, speed capped 14 m/s, spin 18 rad/s) instead of hauling the full body mass by the grabbed forearm; grabber and held body ignore each other's colliders while held (`IgnoreBodyCollision`, restored 0.6 s after release); a held body takes no impact damage (`ImpactDamage` returns while `_grabbedBy != null`). HUD: G key labelled GRAB (HOLD); while you hold a robot the keyboard diagram relabels LMB THROW, RMB TEAR LIMB, SPACE SLAM, Z DRAG, X SUPLEX STANCE.
